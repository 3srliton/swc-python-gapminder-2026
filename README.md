# SWC Python Gapminder Repo
## Workshop hosted by UArizona, Sept. 12-13, 2026

This is the repository for the SWC workshop happening on Sept. 12-13th, 2026 at the University of Arizona. 

First, [Fork](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo) the repository to create a copy of it that is in your own account; you can make changes and host your own code from this workshop in that repo.

Then, clone that repository to your local machine! We'll get started with python there. In the location where you want the repository to be, run:

```bash
git clone git@github.com:sarahstueve/swc-python-gapminder-2026.git
```

NOTE: this is the SSH version of the repository link. If you need to clone using HTTPS (i.e., you haven't created an SSH key), use that link instead! For more information on cloning a repository, click [here](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) to view the GitHub documentation.
